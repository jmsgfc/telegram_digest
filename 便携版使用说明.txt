Telegram 个人消息导出工具
==========================

一、启动
解压整个压缩包，双击 TelegramDigest.exe。
不要只复制 EXE，必须保留同目录下的 _internal 文件夹。

二、首次登录
1. 填写 API ID 和 API Hash。
2. 中国大陆区号保持 +86，手机号框只填写号码。
3. 点击“保存并发送验证码”。
4. 填写 Telegram 客户端收到的验证码。
5. 没有设置两步验证密码时留空。
6. 点击“完成登录 / 检查登录状态”。

三、导出消息
1. 点击“加载会话”。
2. 按住 Ctrl 选择多个群聊或频道。
3. 点击“保存选择”。
4. 点击“导出新增消息”。
5. 点击“打开数据目录”查看 JSONL 文件；每个有新消息的群聊或频道会单独生成一份文件。

四、安全提醒
- data\telegram_digest.session 相当于账号登录凭证，不要发送给他人。
- .env 中包含 API 参数，不要上传或分享。
- 程序只在本机导出消息，不会主动上传给在线 AI。
- 退出或换电脑时，可以删除 data 文件夹以清除本地登录状态和处理进度。

五、读取范围
- 首次运行：每个选定会话最近24小时、最多500条。
- 后续运行：从上次记录位置继续读取新增消息。
- 图片、语音、视频等只显示为媒体消息，不会下载或识别内容。
